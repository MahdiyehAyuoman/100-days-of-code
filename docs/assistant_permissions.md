# دسترسی و محدودیت‌های دستیار Copilot در این مخزن

## توانایی‌ها (Capabilities)

| عملیات | وضعیت |
| ------- | ------ |
| **خواندن فایل‌ها** (Read) | ✅ کامل — دستیار می‌تواند تمام فایل‌ها و دایرکتوری‌های مخزن را بخواند. |
| **جستجو در کد** (Search) | ✅ کامل — جستجوی متنی و معنایی در سراسر مخزن امکان‌پذیر است. |
| **ایجاد/ویرایش فایل** (Write) | ✅ از طریق Pull Request — دستیار می‌تواند فایل بسازد یا تغییر دهد، اما فقط روی یک شاخهٔ جداگانه و از طریق باز کردن PR. |
| **Push مستقیم به main** | ❌ مجاز نیست — هیچ تغییری بدون تأیید کاربر مستقیماً روی شاخهٔ اصلی اعمال نمی‌شود. |
| **حذف فایل/شاخه** | ❌ مجاز نیست — دستیار توانایی حذف مستقیم ندارد. |
| **دسترسی به Secrets/Credentials** | ❌ دسترسی ندارد — هیچ رمز یا کلید API‌ای در اختیار دستیار نیست. |

## نحوهٔ اعمال تغییرات

1. کاربر درخواست تغییر می‌دهد و آن را **تأیید** می‌کند.
2. دستیار تغییرات را روی یک **شاخهٔ جدید** (branch) اعمال می‌کند.
3. یک **Pull Request** باز می‌شود که کاربر باید آن را بررسی و ادغام (merge) کند.
4. بدون تأیید کاربر، هیچ تغییری روی `main` اعمال نمی‌شود.

## محدودیت‌ها (Limitations)

- دستیار نمی‌تواند کد را اجرا یا تست کند مگر در محیط sandbox ایزوله.
- دسترسی به برخی دامنه‌های اینترنتی محدود است.
- تغییرات در دایرکتوری `.github/agents` مجاز نیست.
- دستیار اطلاعات محرمانه (credentials, secrets) را نمی‌خواند یا ذخیره نمی‌کند.
